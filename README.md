# 🌷 海盐葡萄 · 女生个人生活管理 PWA

一个甜酷女孩专属的个人生活管理 PWA，海盐葡萄莫兰迪白紫色调风格。

## ✨ 功能

- AI 热点（实时热搜解读，3小时更新）
- 补品打卡（次日自动清零）
- 食谱合集（分组管理+链接跳转）
- 护肤打卡（周统计表）
- 运动跟练（手表同步+AI推荐）
- 阅读打卡（AI书单+书架）
- 学习打卡（AI单词/语录/文章+词汇本）
- 工作日程（闹钟提醒）
- 幸福碎片（记录+恋爱灵感）
- 纪念日（节假日倒计时+手动纪念日）
- 可爱日记（心情+自动时间戳）

## 📱 使用

iPhone Safari 打开 → 分享 → 添加到主屏幕。

设置中配置 DeepSeek API Key 启用 AI 功能。
